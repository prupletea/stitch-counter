# Stitch counter
A small desktop app I made for my friend who knits. This app calculates how many stitches you need when you're not using exact yarn/needles specified by the pattern you're following.

- Pattern gauge (stitches and cm) - a number of stitches and how many cm it is. Usually, the pattern states the number of stitches per 10 cm.
- Your gauge (stitches and cm) - a number of stitches and how many cm it is. You can set your own number of stitches and then measure the cm, or knit to a set cm and count the stitches.
- Pattern requires (stitches) - how many stitches a certain part of a pattern requires.

After providing all of these numbers, the program calculates approximately how many stitches you will need to match the size intended by the pattern.

There is no release at the moment. To run the app, you need to clone the repo and build it yourself. I might add a release in the future, if necessary.
